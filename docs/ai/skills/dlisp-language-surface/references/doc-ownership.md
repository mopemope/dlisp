# Doc Ownership

## `AGENTS.md`
- 最初に読む短い repo ルール
- 探索順、主要入口、最小テスト導線

## `README.md`
- 人向け quickstart
- 依存、build/run/test、CLI 例
- 公開向けの概要説明

## `FUNCTIONS.md`
- 特殊形式と組み込み関数の短い索引
- source of truth への導線
- 長い意味論や実装解説は置かない

## `spec.md`
- 評価モデル、truthiness、束縛、制御、マクロ、コレクション、JIT/AOT の意味論
- 実装ファイル一覧や導入手順は置かない

## `docs/ai/skills/`
- repo 固有の探索手順
- ドキュメント更新時の運用ルール
- 補助 script と reference

新しい文書を増やす前に、既存 4 系統のどこに属するかを決めること。
